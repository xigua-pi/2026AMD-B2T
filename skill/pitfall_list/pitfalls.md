# 实际踩坑

|现象|原因|处理与证据|
|---|---|---|
|写0x40无效|本比特流未接模式写逻辑|如实固定mode2；软件/XSim三模式，板测仅动态|
|降低门位宽却不降DSP|矩阵、宽总线与高精度回退仍保留|不把低位置零当硬件面积压缩|
|活动策略只5.53%低精度|保守固定阈值适用范围小|报告局部翻转仅约0.99%降低，不冒充功耗|
|开发WER24.16%，板端37.44%|划分与数值执行图不同|独立报告，不混用口径|
|输出缓冲被覆盖|非一致性HP口缓存维护错误|运行中仅invalidate，接收优先启动|
|用户看到开始但没有文字|只有UI更新，没有完整DDR输出|只消费实际写入的完整行并检查寄存器|
|网口已连接但SSH不通|地址、启动卡或VPN路由冲突|先只读诊断；不盲目改网卡与路由|
