# 板端演示

按根 README 启动 `board_server.py`（PYNQ）及 `serve_ui.py`（PC 代理）。工作线程管理 DMA，界面 HTTP 线程读取运行状态；板端处理本地 NPZ 特征。

`stream_decoder.py`将每组 32 路 logits 重复 5 次，检测 onset 阈值上穿，并在延迟 15 步后判决字符。排序表确定句子展示顺序，`reference`字段用于句末可选展示。

通过“开始解码”和“下一条”运行句子，也可在设置中启用连续播放。停止后系统结束事务，完成硬件重配置并释放缓冲，再进入下一句就绪状态。日志保存在传入的 `--log-dir` 中。

波形显示增益默认 ×8，可在设置中调整；PL 使用冻结的 INT8 输入。
