# 板端演示

按根README启动`board_server.py`（真实PYNQ）及`serve_ui.py`（PC代理）。单线程独占DMA，界面HTTP线程只读取状态。数据来自本地NPZ特征；不需要GPU。

`stream_decoder.py`每收到一个完整32-logit输出重复5次，检测onset阈值上穿并等待15步读取字符。`reference`字段在结束后才用于可选展示；排序表只提供记录顺序，不向解码器发射文字。

连续播放默认关闭；“下一条”在空闲时选择下一排序句，再点开始。停止会终止当前事务并重配置后释放缓冲，恢复完成前不能启动另一句。日志保存在传入`--log-dir`中。

波形增益仅影响canvas显示，不修改发给PL的INT8输入。默认×8，可在设置中调整。
